Inventions

Flagship build

LogSentinel

A log-based intrusion detector. It reads web server, SSH and firewall logs, catches brute-force logins, port scans and content-discovery scans, then maps every finding to MITRE ATT&CK and links them into attack chains.

It writes a self-contained HTML/CSS report with CSS Grid summary cards and a findings table, plus CSV and JSON exports.
